\section{How to read this supplement}

The boxes below occur in the same order as the corresponding results in the
main paper. References to figures, tables, theorems, and sections without a
``Supplement'' prefix refer to the main paper. The source file
\texttt{supplement1-findings.tex} is canonical for both this PDF and the Clay
rendering; the main paper contains pointers, not duplicate finding text.
