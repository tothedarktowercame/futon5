# Typed exotype-port census

Generated by `scripts/exotype_ports.clj` from the coordinate system in `mathlib4/DarkTower/MetaCAExample.lean`. No vendored Elisp was run.

Protocol: width 80, 120 steps, seeds `[1 2 3]`; every one of 30 combine fills crossed with `no-mutation`, `rule-permute-s1`, and `rule-permute-rot2`. The phenotype evolves under the current genotype; combine then reads the old/new four-bit context using `futon5.ca.core/context-quadruple`; mutation consumes the combined byte.

The `neighbor-agreement-optionally-flipped-else-fallback` fill uses the flipped/non-nil arm, matching the existing Clojure `blending-flip` default.

Byte-identity gate: **PASSED** across 65536 `(pred, center, succ)` rule triples against `generator.clj`'s existing `metaca-combine :blend`; the same 65536 triples also passed against `:multiply`.

The CSV has one row per seed. `historical-combine-occupants` labels all rows whose combine coordinate was used historically; `historical-dynamic-occupants` labels only exact full occupants in this mutation slice (18 run rows).

## Census result

Across all nine mutation/seed runs per coordinate, the 30 combine coordinates form **11 exact genotype-trajectory classes**. Of the 24 unwritten coordinates, 12 are trajectory-identical to a historical combine coordinate throughout this apparatus. The other 12 form **5 classes with no historical member**, so the sweep is not null. Every one of those novel classes uses `constant-zero`; that fallback is operational when its allele decision can miss, while it is inert under `center-local-rule`.

The template-construction port is likewise inert for every decision except `first-template-match-else-fallback`; this accounts for the largest equivalence classes and shows that the rectangular coordinate system contains many extensionally equal compositions. These are finite apparatus observations, not global equivalence proofs.
