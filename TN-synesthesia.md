# TN-synesthesia: a chord/visual vocabulary

Date: 2026-05-01
Scope: `resources/synesthesia-map.tex`, `resources/gcea.tex`, the design
conversation that produced them.

## 1) What was built

Two LaTeX deliverables, both compiled with `lualatex`:

- `resources/gcea.tex` — chord chart for a GCEA-tuned 4-string banjo,
  parallel to the existing `resources/chicago.tex`. GCEA shares the
  P4--M3--P4 interval pattern with Chicago (DGBE) / CFAD, so all
  fingering shape macros transfer verbatim and only the chord names
  shift (+7 semitones, root on the open low G).

- `resources/synesthesia-map.tex` — a 3-page scaffold for a synesthesia
  map. Designed to be re-shaped through dictation: every visible glyph
  is generated by a macro whose parameters can be reassigned one at a
  time as the friend dictates "this chord feels like X."

## 2) Conceptual evolution of the synesthesia map

The map went through several geometric models, each a redesign rather
than an addition. The final file keeps every model alive as a callable
macro so dictation can swap freely.

1. **Note-disc + interval-glyph + Venn region** (page 1).
   Twelve notes laid out on a chromatic ring as colour-filled discs;
   each interval class has its own colour and TikZ shape (star /
   polygon / starburst / ...); chord/scale/feeling families are
   translucent overlapping polygons drawn on the background layer.
   This is the *static* base — colour for notes, colour+shape for
   intervals.

2. **Snapshots of motion** (a direction we passed through, kept as
   metaphor). G major as a single sine "flowing over hills"; G minor
   as two hyperbolic arcs entering from opposite walls and missing
   across a central rift. Stills meant to *imply* animation.

3. **Vectorscope / Lissajous traces** (page 2 row 1). Each chord =
   the parametric trace
   `x(t) = sum_k sin(2π k t), y(t) = sum_k cos(2π k t)` with k over the
   chord's just-intonation ratios (4:5:6 major, 10:12:15 minor,
   4:5:6:7 dom7, 6:8:9 sus4, ...). Phase encoded as **rainbow gradient
   along the trace** — the new "colour" axis on top of "sound + motion."
   Reference: the YouTube oscilloscope-music tradition.

4. **Beyond the closed orbit** (page 2 row 2). Closed Lissajous orbits
   feel "centred." For other chord-feels we added:
   - `\chordOpposing` — two waves entering from left/right walls,
     interlocking (conversation, not orbit).
   - `\chordHypEnvelope` — sine with `cosh`-envelope that explodes
     outward (asymptotic / unresolved feel).
   - `\chordMobilePole` — Lissajous whose centre orbits a slower
     path, smearing the trace.
   - `\chordHyperbola` — true conic-section hyperbola with asymptotes,
     small radial modulation. (Friend remarked this approximates the
     minor feel.)

5. **Same chord, mobile pole** (page 2 row 3). The chord is *one*
   underlying object; what changes between panels is the viewpoint.
   `\chordViewEllipse{c}{a}{b}{cx}{lbl}` and `\chordViewHyperbola`
   share signatures; vary `(a, b, cx)` and the same G minor reads as
   circle → ellipse → tunnel → hyperbola. A filled dot at `(cx, 0)`
   marks the moving pole; the panel `\clip` turns a displaced ellipse
   into a tunnel automatically (curve crosses the wall, gets cropped).

6. **Layered curves** (page 3). Compositions `B(t) + M(t)` where the
   modulation may have **poles at infinity**. The key insight: don't
   reach actual infinity — let the modulation diverge enough that the
   curve goes off-panel, and the existing `\clip` turns the excursion
   into a hard segment boundary. **Segmentation is then a free
   side-effect of divergence + clipping.** Implemented:
   - `\chordGappySphere` — circle with radial pulse `1/(ε + cos²(ks))`.
     Spikes off-panel at 2k phases per turn, reads as 2k arcs.
   - `\chordSineOnHyperbola` — both branches of `(±cosh u, sinh u)`
     scaled by `(1 + amp · sin(360·k·u))`.
   - `\chordCirclesOnHyperbola` — discrete circle motifs sampled along
     a hyperbolic guide.

The chord identity is the whole stack, not any single layer.

## 3) Vocabulary the file teaches the friend

Inline in the source comments, so dictation can use the words:
*vectorscope*, *Lissajous*, *harmonograph*, *envelope*,
*phase locked / phase drift*, *Möbius / inversion*, *stereographic*,
*projective*, *eccentricity*, *asymptote*, *pole at infinity*,
*mobile 0 / mobile origin*, *layered curves (X on Y)*.

## 4) Lessons / pitfalls worth keeping

- **pgfmath dimension overflow.** `360 * (\k-1) / \vsegments` evaluates
  the multiplication first; for `\k > 45` and `\vsegments = 180` the
  intermediate `360 * 91 = 32760pt` exceeds TeX's max dimension
  (~16384pt) and the loop silently jams at a stale value. Fix:
  parenthesise to divide first — `(\k-1) * (360/\vsegments)`. Same
  trick will be needed for any per-iteration linear ramp through a
  large constant.

- **TikZ shape options inside node parameters.** A `\def` whose body
  contains a comma (e.g. `regular polygon, regular polygon sides=6`)
  cannot be inlined into `[node options]` — TikZ's option parser
  splits on the comma. Use `\tikzset{shape/M3/.style = {...}}` and
  reference as `[shape/M3]`.

- **Region polygons reference node names.** `\drawRegion` uses node
  names (C, E, G), so the notes must be drawn *before* the region
  call. The `on background layer` directive then keeps the regions
  visually behind without reordering the source.

- **Clipping creates "tunnels" automatically.** Once you `\clip` to
  the panel, you don't need separate "displaced ellipse" vs "tunnel"
  templates — push the centre past the wall and the clip crops the
  curve into an arc entering through one side. Same trick segments a
  divergent modulation into discrete arcs.

## 5) Open directions

- **Per-note-coloured Lissajous.** The current vectorscope colours by
  phase (rainbow along trace). Alternative: one Lissajous per
  note-pair in the chord, each in its assigned interval colour. Pulls
  the synesthesia colour vocabulary back into the foreground.

- **Animation.** Everything so far is a snapshot. The natural next
  surface is moving the trace in time — not LaTeX-native; would want
  a PGFPlots / TikZ animations build, or export to SVG/Lottie/manim.

- **Layer composition as a real combinator.** Currently each layered
  template is hand-written. A generic `\chordLayer{base}{modulation}`
  that takes two parametric expressions and composes them would let
  dictation say "circles on (sines on (hyperbolae))" directly.

- **Banjo connection.** The synesthesia map is currently
  instrument-agnostic; tying chord templates back to specific
  fingerings on the GCEA chart would close the loop between the two
  files.

## 6) Files and how to build

```
resources/chicago.tex              # original Chicago-tuning chord chart
resources/gcea.tex                 # GCEA chord chart (this work)
resources/synesthesia-map.tex      # synesthesia scaffold (this work)
TN-synesthesia.md                  # this note
```

Build:

```sh
cd resources && lualatex gcea.tex && lualatex synesthesia-map.tex
```

The synesthesia map currently produces 3 landscape pages (chromatic
ring + 3 rows of 4 chord-snapshot panels each + dictation list).
